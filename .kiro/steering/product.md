# Product Overview

**Expense Budget Visualizer** is a lightweight, client-side personal finance tracker built as a RevoU Coding Camp assignment.

Users can record daily expenses, categorize them, and visualize spending distribution through an interactive pie chart — all without any backend or account setup.

## Core Features

- Add and delete expense transactions (item name, amount, category)
- Real-time total balance display with spending limit alerts
- Pie chart visualization of spending by category
- Monthly summary filter to review spending by time period
- Custom user-defined categories alongside defaults (Food, Transport, Fun)
- Transaction sorting (by amount or category)
- Dark/light mode toggle
- Full data persistence via browser `localStorage` — no server required

## Target Users

Individuals who want a zero-setup, browser-based tool to monitor daily personal spending.
